# Monster Rush auf euren Home-Bildschirm legen

Für Stefan und seinen Kumpel gilt derselbe Link:
https://phanny632.github.io/jarvis-gmail/games/army-rush/?edition=3

1. Diesen Link direkt in **Safari** öffnen. Auf der Missionskarte muss **Edition 03 · Monster Trails** stehen.
2. In Safari **Teilen → Zum Home-Bildschirm** wählen. **Als Web-App öffnen** einschalten, falls der Schalter angeboten wird.
3. **Hinzufügen** wählen. Künftig über das grüne Monstersymbol **Monster Rush** starten.

Beide Geräte bekommen dieselbe Spielversion, speichern Level/Münzen/Upgrades aber getrennt. Es ist keine App-Store-Installation und kein Konto erforderlich. Nach dem ersten vollständigen Laden und Einrichten des Offline-Caches kann das Spiel auch ohne Verbindung starten.

Im Spiel unter **Einstellungen → Spielstand sichern** regelmäßig eine Sicherungsdatei exportieren. Über **Sicherung laden** kann sie auf demselben oder einem anderen Gerät übernommen werden. Website-Daten nicht löschen, solange keine Sicherung vorhanden ist. Ein alter Spielstand innerhalb von Claude kann nicht automatisch von dieser Website übernommen werden.

Apples Anleitung: https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios

Echte Installation und Leistung auf euren beiden iPhones sind erst nach eurem Gerätetest bestätigt.
