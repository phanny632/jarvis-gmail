# Hell Escape auf den Home-Bildschirm legen

Gleicher Link wie bisher, für Stefan und Fiete:
https://phanny632.github.io/jarvis-gmail/games/army-rush/

**Wer die alte „Monster Rush“-App schon auf dem Home-Bildschirm hat:**
1. Die App öffnen, mit Internetverbindung.
2. Die App ganz schließen und neu öffnen. Dann startet Hell Escape.
3. Name und Symbol auf dem Home-Bildschirm bleiben bis zum Neu-Anlegen beim alten Stand. Für das neue Symbol: alte App löschen und Schritt 1–3 unten ausführen.

**Neu anlegen:**
1. Den Link in **Safari** öffnen. Es erscheint „HELL ESCAPE – Ein Game für Fiete“.
2. **Teilen → Zum Home-Bildschirm**. **Als Web-App öffnen** einschalten, falls angeboten.
3. **Hinzufügen**.

Spielstände werden pro Gerät gespeichert. Sicherung unter **Optionen → Spielstand sichern**.
Alte Army-Rush-Spielstände werden nicht übernommen, das alte Spiel bleibt unter **Optionen** erreichbar.

Ob das Update auf echten iPhones so abläuft, ist nicht verifiziert. Apple bestimmt, wann eine Home-Bildschirm-App neu lädt.
